# 字段与计算口径

与网页版一致。修改计算逻辑只改仓库里的 `core/calc.js`,然后运行 `node tools/sync-core.js`。

## 卡片

| 参数 | 含义 |
|---|---|
| `--base N` | 基础返还:每消费 100 元得 N(返现元或积分)。返现卡 `1` = 1% |
| `--rule 类别=N` | 分类加成,可重复。类别名要和记账 `--cat` 完全一致 |
| `--pv N` | 1 个返还单位值多少钱。返现卡 1(默认);1 积分值 0.01 元就填 0.01 |
| `--cap N` | 每月返还封顶,单位与 `--base` 相同(先封顶,再乘 `--pv`)。0 = 不封顶 |
| `--fee N` | 年费(卡片币种) |
| `--waive-spend N` / `--waive-count N` | 免年费条件:全年消费金额达到 N,或笔数达到 N,任一满足即免(等于也算) |
| `--bill-day` / `--due-day` | 每月账单日/还款日(1-31)。31 号在小月顺延到月底 |
| `--currency` | CNY、USD、HKD、EUR、GBP、JPY;默认 CNY |
| `--limit N` | 额度 |

## 计算

- 单笔收益 = 金额 × 每100元得 ÷ 100。分类没有加成就用基础返还。
- 月封顶:同一自然月内该卡所有收益加总后封顶。
- 积分折算:封顶之后乘 `--pv`。
- 年费:满足免年费条件的当年记 0,否则按全额。
- 多币种:各卡用自己的币种记账,报告里的合计按 `rates` 折合人民币。汇率需要用户自己更新。
- 开户奖励年化 = 收益 ÷ 本金 × 365 ÷ 持有天数。
- 开户奖励"资金加权年化" = 已到账总收益 ÷ Σ(本金 × 天数) × 365。

## 开户奖励状态

| 状态 | 条件 | 提醒 |
|---|---|---|
| 持有中 | 未到期 | 7 天内到期会提醒 |
| 已满期 | 到期日已到,尚未确认收益 | 提醒确认收益是否到账 |
| 收益已到账 | 已运行 `offer-got`,尚未转走 | 每天提醒转走本金 |
| 已完成 | 已运行 `offer-moved` | 不再提醒 |

## 提醒规则

`alerts` 输出:开户奖励(7 天内到期、已满期、待转走)以及 3 天内的账单日和还款日。以 `‼` 开头的是需要尽快处理的。
