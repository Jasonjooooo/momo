# X 权重参考分(Chrome 插件)

刷 X 时在每条帖子的互动栏旁边显示一个 **⚖ 参考分**,并自动记录**你自己**帖子的数据,生成复盘页面。

## 参考分怎么算
X 的推荐算法会预测"看到这条帖子的人做某个动作的概率",再乘以权重求和。插件用 **互动数 ÷ 浏览数** 近似这个概率:

```
参考分 = (回复数 × 5 + 转发数 × 1 + 点赞数 × 0.708) ÷ 浏览数 × 1000
```

权重默认取自 X 开源仓库 `xai-org/x-algorithm` 的 `home-mixer/params/param.rs`(2026-11-23)。X 调整权重后,可以在复盘页的「权重设置」里修改。

| 颜色 | 参考分 | 含义 |
|---|---|---|
| 红 | ≥ 60 | 很受算法偏爱 |
| 绿 | 30–60 | 较好 |
| 灰 | 10–30 | 一般 |
| 浅灰 | < 10 | 偏低 |

分档是按常见互动率粗略估计的,建议主要和**你自己的历史帖子**比较。

**局限**:只用页面上公开显示的回复、转发、点赞、浏览数;停留时长、私信分享、复制链接等 X 不公开的数据算不进去;页面上的数字是取整后的(如 1.2K),小帐号误差小、大帐号误差大。所以这**不是 X 内部的真实分数**。

## 安装
1. 下载本文件夹(或解压 `x-weight-extension.zip`)。
2. Chrome 地址栏打开 `chrome://extensions`,打开右上角「**开发者模式**」。
3. 点「**加载已解压的扩展程序**」,选择这个文件夹。
4. 打开 x.com,刷新页面,帖子旁边就会出现 ⚖ 参考分。鼠标停在上面可以看到计算明细。

## 复盘自己的帖子
- 打开**你自己的 X 主页**往下翻,插件会自动记录看到的每条你的帖子。过几天再翻一次,会记录数据增长。
- 点浏览器工具栏里的插件图标,打开「**我的帖子复盘**」:排行、平均分、不同发帖时间的平均分、导出表格。

## 隐私
所有数据只保存在你这台电脑的浏览器里。插件**不联网**、不上传任何内容、不会替你点赞或发帖,只读取页面上已经显示的数字。

## X 改版后失效怎么办
插件靠识别页面结构工作。如果某天参考分不显示了,多半是 X 改了页面,把情况告诉开发者更新即可。
